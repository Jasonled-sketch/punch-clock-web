# 獎章與複習規則

## 獎章分級

| 分數 | 獎章 |
| --- | --- |
| 95 以上 | 超級獎盃 |
| 90 以上 | 鑽石 |
| 85 以上 | 金牌 |
| 80 以上 | 銀牌 |
| 70 以上 | 銅牌 |
| 60 以上 | 獎狀 |
| 60 以下 | 豬頭 |

一天考好幾張時，週曆那一格取**當天最高分**。

及格線 85 分。未達 85 可以換題再考一次。

## 間隔複習

每一題對每個學生有一個熟練度，第 0 級到第 5 級。

| 熟練度 | 下次複習 |
| --- | --- |
| 0 | 明天 |
| 1 | 3 天後 |
| 2 | 7 天後 |
| 3 | 14 天後 |
| 4 | 30 天後 |
| 5 | 畢業，不再排 |

答對升一級，**答錯一律掉回第 0 級**，不管原本升到第幾級。

首頁「今天要複習」抓的是所有考卷裡 `due <= 今天` 的題，跨科目混在一起，一次最多 20 題，其餘順延。沒有到期題目就顯示「今天不用複習」，不要製造假任務。

## 防作弊

作答中切到別的分頁或 App 超過 10 秒，本次整份重新出題並記一次「重出次數」。交卷後看解析時離開不受影響。
