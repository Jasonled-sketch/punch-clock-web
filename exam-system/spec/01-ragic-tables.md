# Ragic 四張表規格

建在家庭帳本的表單集（與 bookkeeping 五張同一個集合），建完**務必把「JR家庭」群組加進每張表的權限**，否則家庭金鑰讀不到，API 會回空或 403。

## 表一：考卷 exams

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| 考卷編號 | 文字 | 例 `chn-cixuan`，唯一 |
| 科目 | 文字 | 國文／英語／理化／地理／公民 |
| 標題 | 文字 | 詞選 如夢令・南鄉子 |
| 單元 | 文字 | 第二課 |
| 題數 | 數值 | 題庫總題數 |
| 指派日 | 日期 | `YYYY/MM/DD`，當天首頁會標「今天要考」 |
| 狀態 | 選單 | 待審核／已上架／已下架 |
| 題庫JSON | 長文字 | 整份題庫，見下方格式 |
| 建立時間 | 日期 | |

題庫 JSON 就是 `banks/*.json` 的 `bank` 陣列，每題長這樣：

```json
{"id":1,"p":1,"r1":1,"s":"題幹，挖空用三個底線","o":["選項A","選項B","選項C","選項D"],"a":0,"e":"解析"}
```

`a` 是正解索引 0~3。`p` 是大題分類編號，對應 `parts`。`r1` 為 1 表示列入第一次測驗優先題庫。

## 表二：題目 questions（選用）

題庫已經整包存在考卷表的長文字欄，這張表只有在你想用 Ragic 介面逐題修改時才需要。**第一版建議先不做**，省一半工。要做的話欄位是：考卷編號、題號、大題、題幹、選項1~4、正解、解析、知識點。

## 表四：複習排程 reviews

| 欄位 | 型態 | 說明 |
| --- | --- | --- |
| 鍵值 | 文字 | `學生_考卷編號`，唯一，一筆存一整張考卷的複習狀態 |
| 學生 | 文字 | |
| 考卷編號 | 文字 | |
| 狀態JSON | 長文字 | `{"題號":{"lv":0,"due":"2026-10-01","ok":2,"ng":1}}` |
| 最近更新 | 日期 | |

一張考卷一筆，不要一題一筆。一題一筆會讓交卷時要寫 25 次，既慢又容易撞到頻率限制。

## 建完之後一定要做的事

Ragic 的欄位 ID 是系統自動給的，**複製表單會全部重編**，所以不能猜。建完四張表跑一次 probe：

```bash
node bot/probe-fields.js
```

它會把每張表的欄位 ID 印出來，照著填進 `bot/exam-module.js` 最上面的 `FIELDS`。

## 三個一定會踩的地雷

1. **寫入只認欄位 ID，不認中文欄名。** 用中文名寫會回成功但欄位是空的，最難查。
2. **日期用斜線 `2026/09/24`。** 用短線寫不進去。
3. **數值欄位送純數字字串。** `"92"` 可以，`"92分"` 會被整欄拒收。
