# 定位器採購指南（路線 B）

## 修正紀錄（重要）

本文件第一版建議用 `JM-VL03`、`VL-02` 這類型號去蝦皮和淘寶搜，**那是錯的**。
Concox / Jimi 是 B2B 品牌，走代理商和 Alibaba，型號不會出現在消費型賣場，
照那樣搜必然找不到。以下是修正後的管道。

## 管道，按實際找得到的機率排序

| 順位 | 管道 | 搜什麼 | 說明 |
|---|---|---|---|
| 1 | **打電話給台灣車隊設備商** | 不用搜，直接問 | 最快確定能不能做。見下面第一節 |
| 2 | **速賣通 AliExpress** | `GT06 4G GPS tracker` | GT06 就是這類機器在國際消費平台的通稱，搜得到 |
| 3 | **淘寶** | 中文描述詞，不要用型號 | 見下面第三節 |
| 4 | 蝦皮 | 幾乎都是綁平台的消費型貨 | 成功率最低，不建議當主力 |

## 一、先打一通電話（最快的路）

台灣有一批做「事業廢棄物清運車輛 GPS」的設備商。這類車機依法要把位置即時回傳到
**環境部指定的伺服器**，所以這些廠商的機器天生就是「可以指向任意伺服器」的設計，
而且他們聽得懂你在問什麼。

環境部審驗合格的廠商名單：<https://gps.moenv.gov.tw/gpszone/dealer.aspx>

名單內比較常見的幾家：

| 廠商 | 網址 |
|---|---|
| 弋揚科技（衛星犬） | eup.com.tw |
| 天眼衛星科技 | skyeyes.tw |
| 神探科技 | hi-gps.com.tw |
| 上德益科技 | sdy-tec.com |
| 鑫豪美科技 | mygps.com.tw |

**打過去只問一句**：

```
你好，我們公司有幾台業務車要做定位。
我不需要你們的管理平台，我有自己的系統。
想問：可以只買車機，然後把它設定成回傳到我自己的伺服器嗎？
如果可以，你們用的通訊協定是什麼？
```

會有三種回答：

- **「可以，協定是 GT06 / JT808」** → 成了。直接報價，這是最省事的結局
- **「可以，但要用我們的協定，我們給你文件」** → 也能做，我照文件再寫一個轉接層，大概一小時
- **「不行，一定要搭我們的平台」** → 換下一家

這條路貴一到兩倍（一台可能 NT$3,000 到 5,000），但你不用當偵探，有人負責，
壞了有保固。以你現在花在找機器上的時間來看，這個價差很可能是划算的。

## 二、速賣通 AliExpress（自己買最實際的管道）

**搜尋關鍵字**（依序試）：

```
GT06 4G GPS tracker
GPS tracker 4G GT06 protocol
vehicle GPS tracker 4G wired ACC
GPS tracker Traccar compatible
```

`GT06` 是這類機器在國際消費平台的通稱，搜得到，而且賣家多半知道這個詞代表什麼。
Traccar 論壇甚至有一個專門的標籤在討論從速賣通買的 GT06 機器。

**篩選**：
- 價格 US$20 到 50
- 選「有線 / wired / hardwired」，不要 magnetic、portable、battery
- 看商品描述有沒有寫 `4G LTE`，以及頻段有沒有 B1、B3
- 看評論裡有沒有人提到 Traccar

**下單前用英文問賣家**：

```
Hi, I will use my own server (Traccar). Please confirm:
1. Is this 4G LTE? Which bands? I need B1 and B3 (Taiwan).
2. What protocol does it use - GT06, JT808, or your own?
3. Can I change the server IP and port by SMS? What is the exact command?
4. Do I insert my own SIM card? Nano or Micro?
```

第 3 題答不出指令格式就換一家。這是生死題。

## 三、淘寶（要用中文描述詞，不要用型號）

淘寶賣家不用 JM-VL03 這種型號，他們用功能描述。搜這些：

```
车载gps定位器 有线 4G
gps定位器 断油电 4G 接线
车队管理 定位器 协议对接
定位器 可改服务器
gps定位器 二次开发
```

最後兩個關鍵字會直接篩出「願意給協定、可以改伺服器」的賣家，數量少但精準。

**旺旺問賣家**：

```
您好，我要对接自己的服务器（Traccar），确认几件事：
1. 这台是 4G 吗？支持哪些 LTE 频段？我在台湾，需要 B1 和 B3。
2. 通讯协议是 GT06、JT808、还是贵司自有协议？
3. 可以用短信指令改服务器 IP 和端口吗？指令格式是什么？
4. SIM 卡我自己插吗？
```

運送選海運，內建電池的機器空運會被擋。

## 四、什麼時候該放棄自己找

你手上已經有一台能用的安智連定位器，對接費是**一次性** 2000 人民幣（約 NT$9,600），
而且接收程式已經寫好測好了。

如果找機器這件事已經花掉你超過三、四個小時，那筆對接費其實比繼續找便宜。
買十台車以上的話，分攤下來一台不到 NT$1,000，更划算。

**判斷點**：再花一個下午打電話給上面那幾家台灣廠商。
問到願意賣裸機並給協定的就走那條，全部拒絕就回頭付安智連那筆錢。
不要再繼續在購物平台上大海撈針。

## 一、確定要買的型號

這幾台有 Traccar 社群的實際使用記錄，不是我猜的：

| 型號 | 廠牌 | 型式 | Traccar 狀況 |
|---|---|---|---|
| **JM-VL03** | Concox / Jimi | 4G LTE Cat 1，有線接電 | 走 GT06，5023 埠。已知 SOS 警報不被辨識（我們用不到） |
| **VL-02** | Jimi | 4G，有線接電 | 走 GT06，5023 埠，社群回報正常 |
| VL512 | Jimi | 4G，OBD 插頭 | GT06。OBD 款安裝快但容易被拔 |
| S06A / S5L | Seeworld 斯沃德 | 4G，有線接電 | 走 GT06，5023 埠，論壇有實例。台灣有通路 |

**首選 JM-VL03 或 VL-02。** 兩台都是 Concox / Jimi 出的，這家是全球出貨量最大的
車載定位器廠之一，韌體穩定，Traccar 社群資料最多，卡住時查得到答案。

價格參考：淘寶約人民幣 120 到 200（約 NT$580 到 960），蝦皮台灣賣場約 NT$1,000 到 1,800。

## 二、蝦皮搜尋完整步驟

### 步驟 1：用這些關鍵字，依序試

**A 組：直接搜型號（成功率最高，先試這組）**

```
JM-VL03
VL-02 GPS
Concox GPS
Jimi GPS 定位器
斯沃德 GPS
Seeworld GPS
```

搜得到就直接跳到步驟 3 驗規格。搜不到再往下。

**B 組：搜功能特徵**

```
GPS追蹤器 接電
GPS定位器 有線 4G
GPS追蹤器 自己插卡
車隊 GPS 定位器 4G
GT06 GPS
```

關鍵詞是「**接電**」「**有線**」「**自己插卡**」。
這三個詞會濾掉一大半「免插卡、內建電池、綁平台」的消費型貨。

**C 組：搜開發者向（數量少但品質高）**

```
GPS 定位器 自訂伺服器
GPS 追蹤器 可改IP
GPS tracker 開放協議
車隊管理 GPS 二次開發
```

搜到的通常是做車隊生意的賣家，聽得懂你在問什麼。

### 步驟 2：篩選

搜尋結果頁上：

- **價格區間設 NT$600 到 2,500**。低於 600 幾乎都是 2G 或玩具，高於 2500 是綁服務的方案
- **出貨地選「台灣」**，除非你能接受等兩週
- **排序用「銷量最高」**，不要用「價格最低」
- 直接**略過**標題有這些字的：免插卡、終身免費、終身平台、內建卡、無需SIM、磁吸、免安裝

### 步驟 3：點進去看這五個地方

| 看哪裡 | 要看到什麼 | 看到這個就關掉 |
|---|---|---|
| 規格表「網路」 | 4G LTE Cat 1 / Cat 4 | 2G、GSM、GPRS |
| 規格表「頻段」 | 有列出 B1、B3 | 只寫「全網通」而不列頻段 |
| 規格表「SIM」 | Nano SIM 卡槽 / 自行安裝 | 內建 eSIM、已含流量卡 |
| 規格表「電源」 | 9-36V 或 9-90V 接線 | 內建電池、USB 充電 |
| 商品描述 | 有提到協定名稱 | 只提「下載我們的 App」 |

規格表看不到「頻段」是最常見的狀況。這時候就去問賣家。

### 步驟 4：問賣家（最重要的一步）

**在賣場問答區問，不要用聊聊。** 問答區是公開的，賣家回答比較謹慎，
而且你也能看到別人問過什麼。

直接複製這段：

```
您好，我要接自己的伺服器（Traccar），麻煩確認五件事：

1. 這台是 4G 嗎？支援台灣哪些 LTE 頻段？我需要至少 B1 和 B3。
2. 通訊協定是 GT06、JT808、還是貴司自有協定？
3. 可以用簡訊指令改伺服器 IP 和埠嗎？指令格式是什麼？
4. SIM 卡是我自己插嗎？卡槽是 Nano 還是 Micro？
5. 沒訊號時（例如地下停車場），位置會暫存並在恢復後補傳嗎？

麻煩幫我確認，確認後我會下單。謝謝。
```

### 步驟 5：判讀回答

| 題目 | 通過 | 不通過 → 換一家 |
|---|---|---|
| 1 頻段 | 明確列出含 B1、B3 | 只說「台灣可用」「全網通」而講不出頻段 |
| 2 協定 | GT06 或 JT808（Traccar 兩種都支援，只是埠不同） | 「我們自己的協定」「只能用我們 App」 |
| 3 改伺服器 | 給出完整指令格式 | 「不能改」「要找原廠」「我不清楚」 |
| 4 SIM | 自己插，Nano 或 Micro 都行 | 「卡已內建不能換」 |
| 5 補傳 | 「會補傳」最好 | 「不會」還能用，只是地下室那段會缺資料 |

**第 3 題是生死題。** 賣家給不出指令格式，這台對你就是廢的，
不管它多便宜、評價多好。上次那台就卡在這裡。

## 三、淘寶買法（推薦，比蝦皮準）

1. 搜尋框直接打型號：`JM-VL03` 或 `VL-02 gps` 或 `concox 车载定位器`
2. 選「**天猫**」或銷量前幾名的店，避開評價少的
3. 規格選「**接线版 / 有线版**」，不要「免安装」
4. 選項如果有「**不含卡 / 不带卡**」就選那個，要自己插台灣的卡
5. 旺旺問賣家，把上面五題的簡體版貼過去：

```
您好，我要接自己的服务器（Traccar），确认五件事：

1. 这台是 4G 吗？支持哪些 LTE 频段？我在台湾，需要 B1 和 B3。
2. 通讯协议是 GT06、JT808、还是贵司自有协议？
3. 可以用短信指令改服务器 IP 和端口吗？指令格式是什么？
4. SIM 卡我自己插吗？卡槽是 Nano 还是 Micro？
5. 没信号时位置会缓存并补传吗？
```

6. 運送選「官方直邮 / 海運快遞」，內建電池的機器空運會被擋，海運比較不會卡關

## 四、絕對不要買

| 類型 | 為什麼 |
|---|---|
| 標「免插卡」「終身平台」「收到即用」 | SIM 焊死、伺服器鎖死，就是你上次踩的坑 |
| 規格表寫 2G / GSM / GPRS 的 | 台灣 2G、3G 已關台，插電也沒用。注意 GT06 是「協定」名稱，同名機器有 2G 也有 4G 版，要看規格表不能看名稱 |
| 磁吸電池款、免安裝款 | 要定期充電，而且會被人拿下來收進抽屜 |
| 只寫「全網通」不列頻段的無牌貨 | 多半是中國專用頻段（B39/B40），台灣收不到訊號 |
| 主打「抓猴」「徵信」的賣場 | 賣的是隱蔽小機，不是車隊設備，通常沒有 ACC 偵測 |

## 五、要一起買的東西

| 項目 | 規格 | 概略價格 | 注意 |
|---|---|---|---|
| 定位器 | 見上 | NT$600 到 1,800 | **買兩台**，一台裝車一台當測試機 |
| SIM 卡 | 一般門號或預付卡 | 月租 NT$50 起 | **必須能收簡訊**。純數據物聯網卡設定不了伺服器 |
| 安裝工資 | 電裝行接三條線 | NT$500 到 1,000 | 常電、ACC、地線 |
| 3A 保險絲 | 接常電時 | 數十元 | 原廠手冊建議 |

**為什麼要買兩台**：每次要調參數、重發簡訊、看指示燈，
都要鑽進駕駛座底下。桌上放一台接 12V 變壓器，差價幾百塊省下的是好幾個下午。

## 六、收到貨當天的驗收流程

按順序做，每一步過了再做下一步。任何一步卡住，**在七天鑑賞期內退貨**。

1. **不接車，桌上接 12V 變壓器**。確認會開機，指示燈有反應
2. **SIM 卡先插手機，把 PIN 碼鎖關掉**，再插進定位器。沒關 PIN 會開不了機
3. 等三到五分鐘，看 GPS 燈是否轉成定位成功的狀態（各廠燈號不同，看說明書）
4. **發簡訊改伺服器**，用賣家給的指令格式。多數機器會回一封確認簡訊
5. **Traccar 後台看得到這台機器**（先在後台用 IMEI 新增裝置）
6. **拿著它在公司附近走一圈**，軌跡正常
7. **Ragic 長出記錄**
8. 以上全過，才裝上車

前六步都在辦公室做完，裝車那天就只剩接線。

## 七、台灣的特別注意

- **2G、3G 已全面關台**。標 GSM、2G、GPRS 的機器在台灣完全不能用，插電也沒訊號
- **頻段至少要有 B1（2100MHz）和 B3（1800MHz）**。中國專用的 B39、B40 在台灣收不到
- **SIM 卡的 PIN 碼鎖要先關掉**，否則定位器開不了機。這個坑每個人都踩一次
- **蝦皮有七天鑑賞期**，驗收不過就退。不要因為「才一千多塊」就留著

## 八、如果全部都失敗

蝦皮和淘寶都找不到能改伺服器的，還有兩條路：

1. **找台灣車隊設備商**。遠建科技（yj-gps.com.tw）這類做車隊生意的，
   直接說「我要自己的伺服器，不用你們的平台」。貴一到兩倍但省事，也有人可以問
2. **回頭付安智連那 2000 人民幣**。你手上那台就能用，程式也寫好了。
   多買幾台車之後，這筆一次性費用分攤下來就不貴
