# 定位器採購指南（路線 B）

## 先講結論

買**有線接電式、4G、明確標示 GT06 協定、可用簡訊改伺服器**的機器。
不要買「收到即用」「終身平台」「免插卡」這類——那些伺服器都鎖死，資料進不了你的系統。

## 型號推薦（依把握度排序）

### 第一順位：Concox / Jimi JM-VL03

- 4G LTE Cat 1，2G 回退
- 有線接電，隱藏安裝
- Traccar 論壇有實際使用回報，走 GT06 協定 5023 埠
- 已知小問題：SOS 警報在 Traccar 不會正確辨識。這個功能我們用不到，不影響
- 原廠：iconcox.com，台灣可在蝦皮找代購或水貨

Concox（深圳中位科技，品牌另有 Jimi）是這個領域出貨量最大的廠之一，韌體相對穩定，
Traccar 社群資料也最多，出問題比較查得到。

### 第二順位：Seeworld 斯沃德 有線 4G 款

- Traccar 論壇確認走 GT06，5023 埠（論壇有 S06A、S5L 的實例）
- 台灣有通路和保固，壞了有人理
- 型號會改版，下單前務必用下面的問答稿確認

### 不建議

| 類型 | 為什麼不要 |
|---|---|
| 【追蹤王】、TS 生活趣這類台灣通路「免插卡」款 | SIM 焊死或綁定平台，伺服器改不了，資料鎖在他們 App |
| 標 2G / GSM / GT06N 原始款 | 台灣 2G、3G 已關台，完全不能用 |
| 無牌白牌最便宜款 | 同一款不同批次韌體可能不一樣，協定沒人說得準 |
| 磁吸電池款 | 要定期充電，而且會被人拿下來。接車電才是正解 |

## 下單前貼給賣家的問答稿

直接複製，五題都要有明確答案再下單：

```
您好，我要用自己的伺服器（Traccar），想先確認幾件事：

1. 這台是 4G 嗎？支援台灣哪些 LTE 頻段？（我需要至少 B1 和 B3）
2. 通訊協定是 GT06 還是 JT808？還是貴司自有協定？
3. 可以用簡訊指令改伺服器 IP 和埠嗎？指令格式是什麼？
4. SIM 卡是我自己插嗎？卡槽是 Nano 還是 Micro？
5. 沒訊號的時候（例如地下停車場），位置會暫存並在恢復後補傳嗎？
```

**怎麼判讀回答**

- 第 1 題答不出頻段 → 跳過，這種賣家自己也不知道在賣什麼
- 第 2 題答 GT06 或 JT808 都可以，Traccar 兩種都支援，只是埠不同。答「我們自己的協定」或「只能用我們 App」→ 跳過
- 第 3 題給不出指令格式 → 跳過，這就是你上次踩到的坑
- 第 4 題答「卡已內建不能換」→ 跳過
- 第 5 題答「會補傳」最好。答「不會」還能用，只是地下室那段軌跡會缺

## 蝦皮搜尋關鍵字

```
4G GPS 追蹤器 接電
GPS 定位器 GT06
車用 GPS 追蹤器 自己插卡
JM-VL03
```

搜尋結果先看賣場問答，很多人會問到協定和改伺服器的事，答案通常比客服回得快。

## 還要買什麼

| 項目 | 說明 | 概略價格 |
|---|---|---|
| 定位器本體 | 如上 | NT$800 到 1,500 |
| SIM 卡 | 一般門號或預付卡，**必須能收簡訊**（設定伺服器要用）。純數據物聯網卡收不到簡訊，設不了 | 月租 NT$50 起 |
| 安裝工資 | 電裝行接常電、ACC、地線三條 | NT$500 到 1,000 |

建議第一次買**兩台**。一台裝車，一台放桌上接 12V 變壓器當測試機。
每次要調參數都跑去車上鑽駕駛座底下，很快就會後悔沒買第二台。

## 裝機順序

1. 桌上接 12V 變壓器，插 SIM 卡，先確認會開機、會定位（指示燈）
2. 發簡訊改伺服器，在 Traccar 後台看得到這台機器
3. 拿著它在公司附近繞一圈，確認軌跡正常
4. 確認 Ragic 有長出記錄
5. 都對了才裝上車

前四步在辦公室做完，裝車那天就不會手忙腳亂。

## 台灣特別注意

- **2G、3G 已全面關台**，只有 4G 可用。型號標 GSM、2G、GT06N 的都是廢鐵
- 頻段至少要有 **B1（2100MHz）和 B3（1800MHz）**。只有 B39/B40 這種中國專用頻段的機器在台灣收不到訊號
- SIM 卡插進去前先用手機**關掉 PIN 碼鎖**，否則定位器開不了機
