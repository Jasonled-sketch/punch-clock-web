# G900L / G900LS / G900LSC 設定指令

來源：賣家（深圳市源富信通电子）提供的原廠指令表 `G900LSC指令表 V1.2`。
韌體版本示例 `ZDR16S001V1.01.02`。

**確認是 GT06**：指令表裡有 `GT06SEL`、`GT06ICCID`、`GT06IEXVOL`、`GT06GPRSGMT`
這些 GT06 專屬設定，所以 Traccar 走 gt06 協定、5023 埠。

---

## 一、開箱設定，照順序發簡訊

把定位器的 SIM 門號存進手機，逐條發，每條都會回一則確認簡訊。
**確認回覆正確再發下一條**，不要一次全部貼過去。

```
APN,internet,,#
```
設定 APN。台灣三家電信都是 `internet`。逗號要保留當佔位符。
回覆應為 `APN:INTERNET,,`

```
SERVER,1,你的網域,你的埠,0#
```
指向你的 Traccar。Railway 的話網域和埠都用 TCP Proxy 給的那組
（像 `shuttle.proxy.rlwy.net` 和 `15140`），**不是容器內的 5023**。
自架主機就填你的網域和 5023。

```
TIMER,30,300#
```
**這條最重要，一定要改。** 原廠預設是 `TIMER,20,3600#`，
第二個參數 3600 代表熄火後一小時才回報一次定位。

那樣設定的話，一次 40 分鐘的客戶拜訪只會收到「停下」和「開走」兩個封包，
中間完全沒有資料。程式雖然有補救機制（會在車子開走時回頭推估出這次停留，
並標記 `inferred_sparse`），但到達和離開時間都只能用估的。

改成 300 秒（5 分鐘）之後，停留期間每 5 分鐘一個點，時間就準了，
流量也只有一天幾百 KB。範圍限制：第一個參數 5 到 60 秒，第二個 60 到 3600 秒。

```
HBT,180,180#
```
心跳包間隔，點火和熄火都 180 秒。範圍 60 到 300 秒。

```
SUPPRESS,1#
```
開啟 GPS 漂移抑制。停車時的座標會穩很多，直接影響停留判斷的準確度。

```
ANGLE,1#
```
開啟拐點補傳。轉彎時多送一個點，軌跡比較完整。

## 二、絕對不要動的兩個設定

```
SZCS#GT06GPRSGMT=0     ← 保持 0，不要改成 1
```
**這條改錯會讓所有記錄的時間差 8 小時。**

預設 0 代表「固定用 0 時區（UTC）上報平台」。Traccar 的 GT06 解碼器就是
按 UTC 解讀時間戳，所以 0 才是對的。改成 1 會讓裝置改送 UTC+8，
Traccar 仍當成 UTC 解讀，於是每一筆記錄都早 8 小時。

用 `CXCS#GT06GPRSGMT` 可以查現在是什麼。應該回 `READOK: GT06GPRSGMT=0`。

```
SZCS#GT06SEL=0         ← 保持 0
```
GT06 協定版本。0 是 V1.8，定位資料用 0x12 上報，這是 Traccar 最成熟的路徑。
1 是 V3 用 0x22。沒有特別理由就別改。

## 三、確認設定有生效

```
SERVER#
```
回覆會列出目前的主副伺服器，確認你設的那組有在裡面。

```
PARAM#
```
一次回傳 IMEI、TIMER、HBT、時區、拐點補傳、電子圍欄、漂移抑制、ACC 檢測模式。
確認 `TIMER:30,300` 和 `3A:1`（漂移抑制已開）。

```
STATUS#
```
回傳內置電池電壓、外電電壓、上線狀態、網路訊號、ACC 狀態、GPS 狀態、油電狀態。
裝車後用這條確認 ACC 線有沒有接對：發動引擎時應該回 `ACC:ON`。

```
666#
```
回傳一個 Google 地圖連結加上速度、日期時間、IMEI。
**裝車前就用這條確認定位正常**，不用等 Traccar 那邊。

```
Cxzt#
```
一次查全部，包含版本、協定、IMEI、IP、埠、APN、訊號、電壓、各種間隔。
設定完用這條做最後總檢查。

## 四、裝車相關

**電壓範圍 DC 9 到 90V**，汽車貨車都能接。

**ACC 檢測模式** `DRV,A#`：

| 參數 | 意思 | 什麼時候用 |
|---|---|---|
| `DRV,0#` | 只用震動判斷點火 | 不想拉 ACC 線，只接常電和地線 |
| `DRV,1#` | 只用實體 ACC 線 | 有接 ACC 線，最準 |
| `DRV,2#` | 兩者都用（原廠預設） | 有接 ACC 線時建議維持這個 |

ACC 準不準直接影響拜訪判斷：程式在熄火時只要 1 分鐘就認定「停妥了」，
引擎沒熄則要 3 分鐘。所以**能接 ACC 線就接**，不要只用震動。

**LED 燈號**（裝車現場除錯用）：

| 顏色 | 狀態 | 意思 |
|---|---|---|
| 綠（網路） | 常亮 | 沒有電信訊號 |
| 綠 | 1 秒閃 1 次 | 訊號正常，但還沒連上平台 |
| 綠 | 3 秒閃 1 次 | **已連上平台，這是正常狀態** |
| 藍（定位） | 1 秒閃 1 次 | GPS 已定位 |
| 藍 | 不亮 | 沒定位，或裝置休眠中 |
| 紅（電源） | 常亮 | 外電正常 |
| 紅 | 1 秒閃 | 外電沒了，正在吃內建電池 |

裝好之後綠燈應該是 3 秒閃一次。還在 1 秒閃就是伺服器位址設錯或 Traccar 沒起來。

## 五、盲區補傳

原廠說明：單一伺服器 IP 最多暫存 300 筆 GPS 資料。

以 `TIMER,30,300#` 計算，行駛中 30 秒一筆，300 筆等於**約 2.5 小時的行駛資料**。
地下停車場、山區隧道出來後會自動補傳，不會缺一段軌跡。

超過 2.5 小時完全沒訊號的話，最舊的資料會被覆蓋。一般用車不會遇到。

## 六、刻意不用的功能

**斷油電 `RELAY,1#` / `DYD,000000#`**

這台有遠端切斷油電的功能。我們的程式**沒有接，也不建議接**。
行駛中誤觸會造成事故，而且一個被打進來的 HTTP 端點就能讓整個車隊熄火。
真的需要就在賣家的 App 手動操作。

**震動報警、位移報警、超速報警、SOS**

這些會產生額外的告警封包。程式收得到（會記錄下來當 AI 判斷的上下文），
但預設不主動開啟，避免一開始就被通知淹沒。
之後想開，用 `SPEED,ON,10,120,0#` 這類指令，第四個參數 0 代表只走 GPRS 不發簡訊，
才不會產生簡訊費。

## 七、常用指令速查

| 目的 | 指令 |
|---|---|
| 設 APN | `APN,internet,,#` |
| 設伺服器 | `SERVER,1,網域,埠,0#` |
| 查伺服器 | `SERVER#` |
| 設回報間隔 | `TIMER,30,300#` |
| 設心跳間隔 | `HBT,180,180#` |
| 查全部參數 | `PARAM#` / `Cxzt#` |
| 查即時位置 | `666#` |
| 查裝置狀態 | `STATUS#` |
| 查韌體版本 | `VERSION#` |
| 重開機 | `RESET#` |
| 恢復原廠（保留 IMEI/APN/IP） | `FACTORY#` |
| 確認沒被鎖定 | `LOCK123456,0#` |

**買二手或來源不明的機器時**，先發 `FACTORY#` 再重設一次，
避免前一手留下的中心號碼、SOS 號碼或告警設定干擾。
