> Source-quality note for the report writer: in this session only web search and one page fetch (CNCCookbook) worked. Direct fetches of instructables.com, powerstrokearmy.com, tractorbynet.com and thefabricator.com were blocked by the session network allowlist, so most findings below come from search-result extracts of forum threads, not from reading whole threads. Quotes are as returned by search; where a search returned several threads without saying which thread a quote came from, I say so. Forum content is anecdotal builder opinion, not tested data. ## 1. Chop saw integration: recessed bay, side wing, receiver mount, or separate cart

### Takeaway
All four layouts are documented. The recurring builder consensus in the forum extracts is "saw bed flush with the table top so the table supports long stock, but the saw must be able to leave the top" (slide-out, flip-up, receiver-mounted or on its own cart), because a saw living permanently on the welding surface gets in the way and throws grit onto it. No source gave a chop-saw bed height, so the recess depth has to be set from the user's own saw, ideally with an adjustable saw tray.

### Cited Findings

Flush / lowered mounts
- One builder set the saw on a 3/8" (about 9.5 mm) steel plate and lowered that mount: "I lowered the chop saw mount itself to be flush with the table to make cutting long material easier." The same build made the mount slide out so the saw can be stowed. — [Powerstroke Army forum post](https://www.powerstrokearmy.com/goto/post?id=1236750) (search extract; page not fetched)
- A Wheel Horse forum builder mounted the chop saw so it sits flush with the table so stock can be fed across the table into it; the same builder used a vise that is clamped ("pinched") to the table so it can be moved. — [Wheel Horse Forum, "Welding table"](https://www.wheelhorseforum.com/topic/70249-welding-table/) (search extract)
- A forum suggestion is to build a box or recess so the saw base sits level with the bench top. — one of [Hobart Weld Talk, "mounting a chop saw?"](https://weldtalk.hobartwelders.com/forum/weld-talk-topic-archive/welding-projects/22653-mounting-a-chop-saw) / [Hobart Weld Talk, "Chop Saw Table ideas"](https://weldtalk.hobartwelders.com/forum/equipment-talk/metal-working-tools/27793-chop-saw-table-ideas) (search returned these together; exact thread not verified)
- A Garage Journal thread exists specifically asking for the picture of "a welding table [that] has a chop saw mounted flush in it", which shows the flush-bay idea is a known reference design among builders. — [Garage Journal](https://www.garagejournal.com/forum/threads/help-locating-a-post-or-picture-of-a-welding-table-has-a-chop-saw-mounted-flush-in-it.313364/) (title only; content not read)
- Extreme How-To's welding table article lists a chop saw among the tools and says of adjoining surfaces "you want them to fit flush together". — [Extreme How-To](https://extremehowto.com/how-to-build-a-welding-table/) (search extract)

Receiver-mounted / flip-up / slide-out

Separate saw cart / roller outfeed at table height
- A FARM SHOW build converted two 10-ft used conveyor roller sections into a cutting table for a metal chop saw, with the rollers set "to match the height of my welding table". — [FARM SHOW](https://farmshow.com/a_article.php?aid=14184) (search extract; which of two FARM SHOW articles not verified, see also [aid=20963](https://db.farmshow.com/a_article.php?aid=20963))

Sparks, abrasive dust, swarf
- Sparks from a chop saw mostly leave the back of the saw; one user reported that leaving the bottom open under the saw lets sparks drop out; another built a spark catcher that "catches about 90%" of what flies out the back, with some still falling below the saw. — forum group: [Hobart "Chop Saw Table ideas"](https://weldtalk.hobartwelders.com/forum/equipment-talk/metal-working-tools/27793-chop-saw-table-ideas), [WeldingWeb, "What to do about metal shavings from chop saw, etc."](https://www.weldingweb.com/threads/what-to-do-about-metal-shavings-from-chop-saw-etc.713652/) (exact thread per claim not verified)
- A spark guard made from a 14-in. square steel plate "angles toward the saw and mounts on a pair of angle irons"; the builder made it because of wooden shop walls. — [FARM SHOW](https://farmshow.com/a_article.php?aid=14184) (search extract; article ID not verified between 14184 and 20963)
- A chop saw cabinet made from a 275-gal fuel oil tank "catches fines, traps sparks and provides an easy-to-clean work surface". — [FARM SHOW, "Chop Saw Cabinet Cuts Down Mess"](https://farmshow.com/a_article.php?aid=18810)
- One hobbyist enclosed the saw (a plastic freezer door was used) and others recommended building a sheet-metal back so sparks do not go everywhere. — [TractorByNet, "My Chop Saw stand"](https://tractorbynet.com/forums/threads/my-chop-saw-stand.139232) (search extract)
- A patented "spark trap" is a base plate under the chop saw that collects sparks and filings, with side channels that locate the saw. — [US7520201B1](https://patents.google.com/patent/US7520201)
- For plasma/cutting areas, builders funnel debris down: "All the slag and dust funnels down to the bucket." — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm); a hopper with removable tray under a cutting table and cutting over water to control sparks and smoke are also suggested. — [TractorByNet, "Cutting and Welding Table"](https://tractorbynet.com/forums/threads/cutting-and-welding-table.391946/post-5007484) (search extract)
- Do not vacuum abrasive-saw sparks into a wood-dust style collector: metalworking dust collectors use a metal drawer and a non-sparking aluminium fan/housing to reduce fire risk. — [Lowe's listing, JET JDCS-505 metalworking dust collector stand](https://www.lowes.com/pd/JET-JDCS-505-Metalworking-Stand-Dry-Dust-Collector-with-Polyester-Filter/5015847319) (search extract)

### Inferences
- Footprints cluster around 520-530 mm long x 250-300 mm wide for the machine and roughly 445 x 245 mm for the cast/pressed base, at 16-18 kg. A saw bay/tray with a clear opening of about 600 x 350 mm should take any common 14" saw plus room for the vise handle and cord; this must be confirmed against the user's saw.
- Because no bed height was found, the safest design is a saw tray whose height is adjustable (slotted bolts, jack screws or shim plates) rather than a fixed-depth welded pocket. It also lets a future replacement saw be re-levelled.
- Putting the saw at one short end of the 180-240 cm table, bed flush, turns the whole table length into the support for long stock on one side; a short folding/slide-out arm or a roller stand is then only needed on the off-cut side.
- Combining the sources: sparks leave the rear of the saw and grit falls under it, so the bay should (1) aim the saw's rear away from the welding surface, the welder, stored tools and the outlet box, (2) have an open bottom with a steel chute to a metal bucket, and (3) have a sheet-metal back/side shield. A removable flush cover plate over the bay when the saw is stowed would restore full table area; this is my design inference, I found no documented drop-in-cover build.
- Pros/cons synthesis (inference from the cited builds):
  - (a) Recessed fixed bay: best long-stock support and always ready; costs permanent table area and puts abrasive grit closest to the flat top.
  - (b) Lowered side wing/shelf: same flush support without cutting into the top; widens the table (matters for a mobile table and doorways) and adds an overhung 16-18 kg load.
  - (c) Receiver or slide-in mount: saw disappears when not needed and the same sockets take a vise/grinder; needs slop control and a place to store the saw, and re-levelling repeatability depends on the fit.
  - (d) Separate cart at table height: keeps all grit and sparks off the welding table and can be parked outdoors/downwind; costs floor space and needs height matching on an uneven floor.

### Gaps
- No manufacturer source gave the bed/vise-table height above the bench for any 14" abrasive saw (Makita 2414/LW1401, Bosch GCO, HiKOKI CC14, Taiwanese 14" 切斷機). The user must measure their own saw.
- No dimensions found for the Makita 2414NB itself, HiKOKI CC14STD, or 力山 (Rexon) models.
- I could not open the Hobart, New Ag Talk, Garage Journal or WeldingWeb threads, so per-thread attribution of several quotes above is unverified.
- No documented build of a drop-in bay with a flush cover plate, and no measured data on how far abrasive grit travels onto a table top.
- No Chinese-language source on 焊接桌 + 切斷機 integration was found.

## 2. Receiver-hitch / modular tool mount systems

### Takeaway
2" square receivers under the table edge or at the corners are the standard way to make a vise, bench grinder, chop saw tray or bender removable. The known weakness is slop; builders fix it with weld beads ground to fit plus a clamping bolt through a welded nut, and they keep the pin near the outer end so it can be reached.

### Cited Findings
- Receiver tube stock quoted by builders: 2.530" OD with 0.250" wall, about 2.03" ID, leaving about 0.030" clearance for a 2" square insert; inserts are "normal 2x2x1/4"" tube. — [TractorByNet, "Receivers on welding tables"](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/) (search extract)
- "The typical 2" receiver is pretty sloppy." — [TractorByNet, same thread](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/post-5008914); hitch shanks are often undersized and receiver tubes vary. — [Ford-Trucks forum](https://www.ford-trucks.com/forums/1205384-2-1-8-receiver-size.html)
- Slop fix 1: "What I did to take out the slop, is make a plug / round weld at the front, and back of the stinger", then grind to a snug fit. — [TractorByNet, "Receivers on welding tables"](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/page-2) (search extract)
- Slop fix 2: weld a 3/4" nut over a hole drilled in the side of the receiver and use a bolt to clamp the insert; "The 3/4" bolt takes the slop out of the fit." — [same thread](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/post-5009508)
- Slop fix 3: use two receivers and two inserts per tool to "pretty much eliminate slop". — [same thread](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/post-5009601)
- Trimming/chamfering the insert's leading edge lets you rest the tool's weight on the first 1/2" of the receiver while lining it up. — [same thread](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/latest)
- Retention: put a pin through the receiver like a trailer hitch so the tube cannot slip out; one member uses 5/8" hitch pins and "wouldn't use anything lighter". — [TractorByNet, "Building a Shop / Weld Table"](https://www.tractorbynet.com/forums/threads/building-a-shop-weld-table.392188/post-5110789)
- Pin holes should be near the outer end: "I doubt you'll enjoy reaching that far under your table to pin/un-pin". — [same thread](https://www.tractorbynet.com/forums/threads/building-a-shop-weld-table.392188/post-5037761)
- Cheap ready-made receivers may need internal grinding with a long carbide burr. — [same thread](https://www.tractorbynet.com/forums/threads/building-a-shop-weld-table.392188/post-5111892)
- Mount plate thickness under discussion for the tool plates was 1/4" vs 3/8" (6 vs 10 mm). — [same thread](https://tractorbynet.com/forums/goto/post?id=5111856)
- A 2025 build blog levelled the table first, then added the square receiver tube and levelled it separately so the hitch mount sits level. — [XtremeOwnage, "Shop Table - Part 2 - Wheels & Tool Mounts"](https://static.xtremeownage.com/blog/2025/building-a-shop-table-part-2/)
- Instructables build: hitch-mount vise adapters made from steel plate and 2x2 hitch ball mounts; the vise comes off the table to make room for a large overhanging piece. — [Instructables, "2x2 Hitch Receiver Tooling Adapters and Mounts"](https://www.instructables.com/2x2-Hitch-Receiver-Tooling-Adapters-and-Mounts-for) (search extract; fetch blocked)
- Commercial benchmark: Trick-Tools Versa-Mount vise/grinder mount uses a 5 x 6 in plate with 5/8" holes on 4" centres and four jam bolts that give the platform its rigidity; the arm fits standard 2" receivers; listed at about USD 160-200. Its "Badass" tables have four built-in receivers. — [Trick-Tools](https://www.trick-tools.com/Vise-and-Grinder-Mount-with-Table-Receiver-TT-RM-Combo-13239); [Penn Tool Co](https://www.penntoolco.com/trick-tools-versa-mount-vise-and-grinder-table-mount-tt-rm-combo)
- Tools named as going on receivers: big vise, chop saw, tool grinder, disc sander. — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm)

### Inferences
- Metric equivalents (my arithmetic, not from a source): the US receiver is about 64.3 mm OD x 6.35 mm wall, about 51.6 mm ID, for a 50.8 mm insert, so the working clearance is about 0.8 mm. With Taiwanese metric square tube, a 50x50 insert in 60x60x4.5 (ID 51 mm, about 1 mm clearance) is the closest analogue; 60x60x4.0 gives 52 mm ID (2 mm, sloppy). For a lighter system, a 40x40 insert in 50x50x4.5 (ID 41 mm) or 50x50x4.0 (ID 42 mm) works the same way. Nominal clearance is reduced by the internal weld seam and corner radii, so test-fit actual stock before buying lengths, and expect to grind the seam.
- Given that slop is expected, plan the clamp bolt (M16-M20 nut welded to the receiver side, or two bolts at 90 degrees) from the start rather than relying on a pin alone. The Trick-Tools "four jam bolts" design points the same way.
- For a chop saw tray specifically, the "two receivers, two inserts" approach is the right one: a single 50 mm insert under an 18 kg saw with a long lever arm will rock and lose the flush alignment with the table top.
- Receivers at both short ends and one long side give the most options (saw at one end, vise at a corner, extension arm for long stock on the other end).

### Gaps
- Actual stock sizes and wall thicknesses of square tube available at Taiwanese steel suppliers were not researched; the metric pairings above are untested arithmetic.
- The Instructables page could not be read, so its exact dimensions and lessons are missing.
- No source found on how deep the insert engagement should be; no load ratings for DIY table receivers.

## 3. Grinder storage and grinding areas

### Takeaway
Builders hang grinders on the cart/table side or on a dedicated rack with cord and disc hooks, with the explicit goal of getting grinders and abrasives "up off" the welding surface. Several builders say grinding dirties the table and they want it clean for welding, which argues for a separate grinding position (vise on a receiver at one end) rather than grinding on the top.

### Cited Findings
- "I like hanging them right on the cart..." (angle grinders), with outlets for grinders up under the table lip "where they're protected". — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm)
- Trick-Tools Versa-Mount angle grinder holder (stainless, table-mounted): a disc hook for spare discs on the left; on the right a large hook for the grinder cord or extension cord, a small hook for spindle nuts and a wrench slot. — [Trick-Tools](https://www.trick-tools.com/index/page/product/product_id/20782/product_name/Versa-Mount+Angle+Grinder+Holder)
- Trick-Tools angle grinder storage rack fits table side/pegboard and holds most 4-1/2", 5" and 7" grinders. — [Trick-Tools ITD1848](https://www.trick-tools.com/ITD1848-Angle-Grinder-Storage-Rack-19009)
- Strong Hand Tools "Grinder Rest": magnetic base for steel tables or a C-clamp base for a table edge or leg; includes a cable wrap hook and wrench storage; holds most 5" grinders plus spare discs. — [The Fabricator](https://www.thefabricator.com/thefabricator/product/shopmanagement/grinder-rest-stores-hand-held-grinders-within-reach); [Trick-Tools MGK53](https://www.trick-tools.com/Grinder-Rest-with-C-Clamp-Base-MGK53-8120)
- TMR Customs organizer holds two grinders plus a large assortment of abrasive wheels and is "designed to get your grinders and grinding wheels up off your welding table". — [TMR Customs](https://tmrcustoms.com/products/angle-grinder-abrasive-organizer)
- DIY hanger: a half-pipe with a fork (slot) cut into it, fixed to a wall/surface so the grinder hangs by its gear head. — [Instructables, "7" Angle Grinder Wall Hanger"](https://www.instructables.com/7-Angle-Grinder-Wall-Hanger/) (search extract)
- Progressive Farmer project: a steel rack for grinders, clamps, air and battery tools built from plate and angle iron with a shelf on top; "the tools dictate the overall dimensions"; clamp storage is a tube with flat-bar ends welded under the shelf. — [DTN Progressive Farmer](https://www.dtnpf.com/agriculture/web/ag/news/article/2018/08/01/welding-project-creates-new-storage)
- A builder on grinding at the table: the grinder "makes lots of dirt / mess and I want the table clean when I'm welding". — forum group from a welding-table regrets search, likely [Garage Journal, "Fabrication / Fixturing / Welding table build"](https://www.garagejournal.com/forum/threads/fabrication-fixturing-welding-table-build.169751/) or [WeldingWeb archive, "Welding Table Design Questions/Suggestions"](https://weldingweb.com/vbb/archive/index.php/t-231861.html) (exact thread not verified)
- A builder wished he had fitted sheet metal under the top to catch sparks and grinding debris. — same forum group, e.g. [Tractor Fanatics, "Welding Table Cabinet Build"](https://tractorfanatics.com/threads/welding-table-cabinet-build.1685/) (exact thread not verified)
- Taiwan (Mobile01) discussion of hand-held grinders focuses on safety: always wear eye protection, tighten the disc, hold with both hands, do not remove the guard. — [Mobile01, 手持砂輪機的技巧](https://www.mobile01.com/topicdetail.php?f=635&t=5730537)

### Inferences
- A cheap DIY equivalent of the commercial holders is a row of slotted pipe/angle "forks" on the table's short end or leg, one per grinder (cut-off wheel, grinding disc, flap disc, wire cup), each with a cord hook, plus a 22 mm peg or bolt for spare discs and a hook for the spanner. This copies the features of the Trick-Tools and Strong Hand products.
- Put the grinder rack next to the outlets and next to the grinding position (vise on a receiver), on the end of the table opposite the chop saw's spark stream, so cords do not cross the work surface.
- Hang grinders with the disc facing a sheet-metal backing or downward so a coasting disc cannot touch cords or the user; this is my inference, not from a source.
- A sacrificial sheet-metal pan under the grinding end, sloped to a bucket, follows directly from the "wish I had sheet metal under the top" regret.

### Gaps
- No source covered storing several grinders by disc type or disc storage in detail; no forum consensus on rack location was found.
- No Chinese-language source on 砂輪機 掛架 for welding tables was found; Mobile01 hits were about grinder safety and jigs.
- The Yesterday's Tractors thread "Mini/angle grinder storage ideas?" ([link](https://forums.yesterdaystractors.com/threads/mini-angle-grinder-storage-ideas.1775900/post-11626079)) was found but its content was not read.

## 4. Other tool storage (clamps, drawers vs shelf, torch, consumables, gas bottle)

### Takeaway
Clamp storage is a simple bar or tube under the top or on a separate rolling rack; torch holders are cheap magnetic or edge-mounted parts. Enclosed steel cabinets/drawers are popular as a base, but open drawers and anything wooden under the weld zone are repeatedly flagged for collecting grinding dust and spatter and for fire risk.

### Cited Findings
- Clamp rack: a tube with flat-bar ends welded to the underside of a shelf. — [DTN Progressive Farmer](https://www.dtnpf.com/agriculture/web/ag/news/article/2018/08/01/welding-project-creates-new-storage)
- "Got really tired of digging for clamps so I made this roll-around clamp rack" (utility cart, steel tube frame, rebar arms); wire pegboard racks used for locking pliers; Harbor Freight magnetic MIG torch holders "work well". — [TractorByNet, "Weld table, what tools are your favorite?"](https://tractorbynet.com/forums/threads/weld-table-what-tools-are-your-favorite.473758/latest)
- CNCCookbook's plan: "Outlets on the cart, die grinder and clamp racks", "I'd definitely keep the tool cabinet in the core of the cart", "Love using rolling tool cabinets bought cheap at sales", "Rod storage on one side or the other as convenient". — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm)
- Gas bottles laid horizontally in a cart save space and lower the centre of gravity, but "wrestling them back out of there for refill is probably painful". — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm)
- Drawers: "I think you might find your drawers full of grinding dust and splatter." — forum group, likely [Garage Journal, "Thoughts on building welding table using rollaway chest as base?"](https://www.garagejournal.com/forum/threads/thoughts-on-building-welding-table-using-rollaway-chest-as-base.35941/) (exact thread not verified)
- Fire: "putting wood under where you weld isn't such a good idea. A spark dropped into a crack could start a fire that might not be detected immediately"; metal cabinets suggested instead. — forum group, likely [Tractor Fanatics, "Welding Table Cabinet Build"](https://tractorfanatics.com/threads/welding-table-cabinet-build.1685/) (exact thread not verified)
- Seating: "If you are going to sit at the table for TIG work, and its got a lower height, then a drawer will be in the way." — forum group, likely [WeldingWeb archive](https://weldingweb.com/vbb/archive/index.php/t-231861.html) (exact thread not verified)
- Miller's DIY holder project holds filler metal, torch and helmet at the table, and warns to check for obstructions under the table that would interfere with clamping before mounting. — [MillerWelds, DIY TIG Torch Holder guide](https://www.millerwelds.com/resources/article-library/diy-welding-project-tig-torch-holder-guide)
- Commercial torch holders mount on the table edge (with a cable holder), in side holes, or on a stud that drops into 5/8"/16 mm fixture holes. — [Trick-Tools Table Edge TIG Torch Holder](https://www.trick-tools.com/Table-Edge-TIG-Torch-Holder-13367); [Trick-Tools top-mount holder](https://www.trick-tools.com/ITD21866-Top-Mount-MIG-TIG-Welding-Pliers-Holder-19014)
- A scrap-built mobile welding table used rebar, angle iron, tube, steel castors, chipboard, tin and a drawer slide and is described as having "plenty of storage space for tools and welding gear". — [Bunnings Workshop](https://www.workshop.bunnings.com.au/discussion/100890/mobile-welding-table)

### Inferences
- For this user (welder and gas bottle on their own cart), the table does not need a bottle shelf; the horizontal-bottle idea only adds refill hassle. Keep the table's lower level for weight (stock, clamps, saw when stowed) to improve stability.
- If drawers are wanted, use a closed steel tool cabinet set back from the edges or drawers with an overhanging lip/dust flange, and place them at the end away from the saw and the grinding position. An open lower shelf of expanded metal or spaced slats lets grit fall through rather than accumulate; this is inference from the "drawers full of dust" warnings, not a documented comparison.
- A clamp bar (20-25 mm round bar or 25x25 tube) set 50-80 mm inboard under the long edge keeps F-clamps and locking clamps at hand, but it must not block the edge overhang needed to clamp work to the top (the Miller note about under-table obstructions applies).

### Gaps
- No source directly compared drawers vs open shelf with evidence; findings are single forum opinions.
- Nothing specific found on storing chipping hammer, tape, squares, magnets, wire spools and contact tips at the table.
- No Chinese-language storage write-ups found.

## 5. Electrical: outlets, feed, grounding, work-clamp point, Taiwan supply

### Takeaway
Outlets belong under the table lip or on a leg away from sparks, fed by one cord. The main hazard is that a metal outlet box bonded to the table makes the tool-circuit earth wire a parallel return path for welding current if the work clamp is poorly placed; builders avoid this by always clamping to the work or a dedicated table lug, unplugging tools while welding, and feeding outlets through a leakage breaker. A 14" saw at 110 V draws about 18-20 A, which is the number that sizes the feed.

### Cited Findings
- Outlets "up under the table lip where they're protected" (Big Red Table); outlets grouped with the die grinder and clamp racks; for several machines, one outlet each on the cart "that goes to a single connection [at] the wall". — [CNCCookbook](https://s3.amazonaws.com/s3.cnccookbook.com/CCDIYWeldingTableCart.htm)
- The "ground clamp" is really a work connection, not an earth ground; ANSI Z49.1 says the workpiece or the metal table it rests on must be grounded. — [The Fabricator, "Staying grounded"](https://www.thefabricator.com/article/arcwelding/staying-grounded) (search extract; fetch blocked)
- Failure mode described by forum posters when a receptacle is bonded to the table: "the return welding current could flow through the building to the panel and back through the receptacle ground wire to the bench and work"; a return current from an arc "could melt the 110v boxes, ground, EMT, SO cord and everything to the panel". Anecdotal, not test data. — [TractorByNet, "Ground 120v receptacle bonded to welding table?"](https://www.tractorbynet.com/forums/threads/ground-120v-receptacle-bonded-to-welding-table.273575/post-3225662)
- Options raised in that thread: isolated-ground receptacles (orange, or orange-marked) if you do not want the table earthed through the outlet; feeding the outlets from a GFCI circuit; and clamping the work lead as near the weld as possible, "or better yet - ON the workpiece". Several posters would not tie outlets to the table at all; posters disagree on whether the table should be earthed. — [same thread](https://www.tractorbynet.com/forums/goto/post?id=3225882); [TractorByNet, "Grounding Welding Table - ????"](https://www.tractorbynet.com/forums/threads/grounding-welding-table.251190/post-2932799)
- If a chop saw stays plugged in on the table while welding, the welder may "ground through the saw". — forum group: [Hobart "mounting a chop saw?"](https://weldtalk.hobartwelders.com/forum/weld-talk-topic-archive/welding-projects/22653-mounting-a-chop-saw) / [New Ag Talk](https://talk.newagtalk.com/forums/thread-view.asp?tid=371105&DisplayType=flat&setCookie=1) (exact thread not verified)
- OSHA 1910.254: grounding of the welding machine frame shall be checked, with special attention to safety ground connections of portable machines; where a structure or fixture is used as the return circuit its joints shall be bonded; all ground connections shall be mechanically strong and electrically adequate for the current. — [OSHA 29 CFR 1910.254](https://osha.gov/laws-regs/regulations/standardnumber/1910/1910.254)
- OSHA 1926.351: "conduits containing electrical circuits, shall not be used as a ground return." — [OSHA 29 CFR 1926.351](https://www.osha.gov/laws-regs/regulations/standardnumber/1926/1926.351)
- A ground return cable must have a safe current capacity equal to or exceeding the maximum output of the welding unit. — [29 CFR 1915.56](https://www.law.cornell.edu/cfr/text/29/1915.56)
- Stray welding current through bearings: an AWS forum post from a failure analyst reports arc damage to bearings of rotating equipment from stray welding currents, most likely when ground placement is careless; a shop owner says grounding through shafts or bearings is prohibited; other posters report never seeing such damage. Evidence is for rotating machinery, not table casters. — [AWS forum](https://app.aws.org/forum/topic_show.pl?pid=6697)
- Overheating/arcing at the work clamp comes from excessive circuit resistance, generally a poorly connected work clamp; forum users add that a painted or rusty table gives poor contact. — [The Fabricator, "Consumables Corner: Combating overheating in work clamps"](https://www.thefabricator.com/thewelder/article/consumables/consumables-corner-combating-overheating-in-work-clamps); [TractorByNet, "Scorch/melt on ground clamp"](https://www.tractorbynet.com/forums/threads/scorch-melt-on-ground-clamp.275831)
- Taiwan rules: electric tools and temporary power on sites must have a leakage breaker (漏電斷路器); for portable/mobile electric tools at over 150 V to ground, in wet locations, or on highly conductive places such as metal plates and steel frames, a high-sensitivity, high-speed shock-protection leakage breaker is required, installed on the branch circuit (職業安全衛生設施規則 第243條 as cited by the inspection guidance). — [桃園市政府 營造工地電器作業安全檢查重點](https://gpis.tycg.gov.tw/PwbTycg_Info/Document/ConstructionCheckRegulation/19%e7%87%9f%e9%80%a0%e5%b7%a5%e5%9c%b0%e9%9b%bb%e5%99%a8%e4%bd%9c%e6%a5%ad%e5%ae%89%e5%85%a8%e6%aa%a2%e6%9f%a5%e9%87%8d%e9%bb%9e%e5%8f%8a%e6%b3%a8%e6%84%8f%e4%ba%8b%e9%a0%85.pdf); [勞動部](https://www.mol.gov.tw/1607/1632/1640/20283/post) (search extracts; article numbers may have been renumbered, check 全國法規資料庫)
- Taiwan rules: AC arc welders used in confined conductive spaces or where the worker may touch grounded conductive structures such as steel frames need an automatic voltage-reducing (電擊防止) device; automatic welding is exempted (cited as 第250條 of the older-named rule). — [成功大學 環安資料](https://main-oga.ncku.edu.tw/var/file/60/1060/img/2660/814821192.pdf) (search extract)
- Taiwan labour research statistics list no leakage breaker, no earthing, and wrongly installed or failed leakage breakers among the main causes of electric-shock accidents; 37% of low-voltage safety devices surveyed were not installed as required and another 10% were installed but wrong or failed. — [勞動部](https://www.mol.gov.tw/1607/1632/1640/20283/) (search extract)
- Loads: Taiwan-market 14" cut-off saw listed at 110 V / 60 Hz, 2000-2200 W. — [Yahoo Taiwan listing](https://tw.bid.yahoo.com/item/100038281355/index.md); Bosch GCO 14-24 J is 2,400 W. — [Bosch](https://www.bosch-professional.com/ge/en/products/gco-14-24-j-0601B37200); HiKOKI CC14SF about 2,000 W. — [Cromwell](https://www.cromwell.co.uk/shop/power-tools/cut-off-saws/cc14sfj1z-240v-cut-off-saw-2000w/p/HIK2744417D)

### Inferences
- Current arithmetic: 2000 W / 110 V is about 18 A; 2200 W / 110 V is 20 A; 2400 W / 110 V would be about 22 A (2400 W / 220 V is about 11 A). A 110 V 14" saw therefore needs its own 20 A-class branch (and will exceed a common 15 A outlet strip), and should not share the table feed with a grinder running at the same time. If the user's saw is a 220 V model the feed is much easier. The table's outlet box and cord must be rated for the saw, not for the grinders.
- Layout that follows from the cited hazards: one flexible feed cord with a proper cable gland/strain relief into a metal box mounted under the lip or on a leg at the end opposite the chop saw's spark stream; outlets facing down or sideways with covers; leakage breaker (漏電斷路器) upstream or built into the table's box; cable hooks on the legs so cords and the MIG lead stay off the floor.
- Work-clamp point: a dedicated bare steel or copper lug/bar welded or bolted to the table frame near the top (kept free of paint and rust) gives a low-resistance, repeatable clamp point, consistent with the "poor clamp contact causes overheating" findings. For anything not sitting flat on the top, clamp to the workpiece itself.
- The welder is on its own cart, so the return path is the work lead to the table lug. With the lug on the frame/top, current does not need to pass through casters. The bearing-damage evidence is from rotating machinery, so the caster risk is plausible but unproven; the same practice (clamp on the top or the work, never on a leg below a swivel) avoids it at no cost.
- The parallel-path risk through the tool-outlet earth exists only if the work clamp connection is missing or bad while an earthed tool or box touches the table. Mitigations in order: always clamp to the work/lug before striking an arc; unplug the chop saw and grinders (or switch off the table feed) while welding; keep the leakage breaker in the feed. Whether to bond the outlet box to the table or isolate it is disputed in the sources and should follow local electrical rules; I found no authoritative Taiwan-specific ruling for a DIY table.

### Gaps
- I did not find a source stating Taiwan's residential supply (110 V / 220 V single-phase, 60 Hz) other than the tool listing above; treat the supply description as the user's own given.
- No source on typical angle grinder wattage was collected, so the grinder load is not cited.
- The Fabricator and TractorByNet pages could not be opened, so ANSI Z49.1 wording and poster names are unverified. AWS safety fact sheets and 職安署 primary texts were not retrieved.
- No source on cord reels on welding tables, on conduit-box choice, or on recommended conductor size for the table feed in Taiwan (用戶用電設備裝置規則) was found.
- Whether the user's 250 A CO2/MIG machine needs a 電擊防止裝置 was not determined; the cited rule concerns AC arc (stick) welders.

### Takeaway

## 7. Regrets and warnings

### Takeaway
The strongest repeated warning is against a chop saw that lives permanently on the welding surface; builders also regret dust-collecting drawers, combustible material under the top, grinding on the clean surface, tops that are too thin, and features that block access (pins too far under, drawers where knees go).

### Cited Findings
- "The chop saw being on your actual welding table most of the time will get old, quickly." — forum group: [Miller forum, "First project - Welding table advice"](https://forum.millerwelds.com/forum/welding-projects/580832-first-project-welding-table-advice) / [New Ag Talk, "Chop Saw for Welding Table?"](https://talk.newagtalk.com/forums/thread-view.asp?tid=371105&DisplayType=flat&setCookie=1) (exact thread not verified)
- A layout or welding table "needs to be entirely clear of other items". — same forum group (exact thread not verified)
- One Garage Journal builder does not want anything permanently mounted on the table, for maximum flexibility. — [Garage Journal](https://www.garagejournal.com/forum/posts/11448163/) (search extract)
- Drawers fill with grinding dust and spatter; wood under the weld zone is a hidden-fire risk; drawers/low shelves block sitting at the table; grinding dirties a surface you want clean; wish for sheet metal under the top to catch debris; top should be thicker and better supported against warping. — sources as cited in sections 3, 4 and 6: [Garage Journal rollaway-chest thread](https://www.garagejournal.com/forum/threads/thoughts-on-building-welding-table-using-rollaway-chest-as-base.35941/), [Tractor Fanatics](https://tractorfanatics.com/threads/welding-table-cabinet-build.1685/), [WeldingWeb archive](https://weldingweb.com/vbb/archive/index.php/t-231861.html), [Practical Machinist](https://practicalmachinist.com/vb/fabrication-cnc-laser-waterjet-plasma-welding-and-fab/help-welding-table-build-design-359981) (per-quote attribution not verified)
- Receiver pins placed deep under the table are a regret in waiting; standard receivers are sloppy unless tightened. — [TractorByNet](https://www.tractorbynet.com/forums/threads/building-a-shop-weld-table.392188/post-5037761); [TractorByNet](https://www.tractorbynet.com/forums/threads/receivers-on-welding-tables.391964/post-5008914)
- Leaving the saw plugged in on the table while welding risks the welder returning through the saw's earth. — forum group cited in section 5 (exact thread not verified)
- A height-adjustable extendable stock support "still needs a bit of work", i.e. adjustable outfeed arms are fiddly to get right. — [TractorByNet](https://www.tractorbynet.com/forums/threads/welding-table-build.302426/page-11)

### Inferences
- Layout synthesis for the report writer (inference from all sections; dimensions are proposals to be checked against the user's saw and steel stock):
  1. Keep the main top (75-90 cm x 180-240 cm) completely clear; nothing bolted on top.
  2. Chop saw at one short end on a lowered tray whose bed is flush with the top, the cut line just outboard of the table end, saw rear pointing away from the table and the operator's stored tools. Make the tray removable or stowable: either two parallel receivers (50x50 inserts in 60x60x4.5, or 40x40 in 50x50x4.5, with clamp bolts) or a slide-out/flip-down frame, height adjustable by slotted bolts or shims. Open bottom, sheet-metal back shield, chute to a steel bucket.
  3. Off-cut side: a pull-out arm or roller on the same receiver system, or a separate roller stand; add a clamp-on length stop that rides the table's long edge.
  4. Opposite short end: receiver for a vise (the grinding position), grinder forks with cord and disc hooks on the leg, and the outlet box under the lip, all away from the saw's spark stream.
  5. Long sides: clamp bar set inboard under one edge, torch hook and helmet hook on a leg, cable hooks; no bottle shelf.
  6. Lower level: open, grit-shedding shelf for stock and the stowed saw; any drawers in a closed steel cabinet away from both ends.
  7. Electrical: single feed cord with strain relief, leakage breaker, branch sized for the saw (about 20 A at 110 V), dedicated bare work-clamp lug on the frame near the top, tools unplugged or feed switched off while welding.
- The option that best satisfies the "saw must leave the top" warning while keeping "the table is the infeed support" is the removable flush tray at the table end (hybrid of options a/b/c). A separate cart (d) is the lowest-grit choice if floor space allows.

- Per-quote attribution for several regret quotes could not be verified because the forum pages could not be opened.
