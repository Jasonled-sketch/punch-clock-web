# 宮廟雲 入門版：主機安裝與維修手冊

入門版在廟裡的主機上執行，**不需要網路**。有網路的廟可以另外開啟雲端加密備份。

## 出貨前（公司內）

1. 主機：無風扇迷你主機，Windows 11 專業版，SSD。
2. **BitLocker 全碟加密**：設定 → 隱私權與安全性 → 裝置加密／BitLocker。修復金鑰印出來，放進合約袋，**不要**存在主機上。
3. BIOS 設定密碼，關閉 USB 開機。
4. 建立兩個帳號：`管理員`（公司維修用）與 `櫃台`（一般使用者，自動登入）。
5. 把整個 `local-server` 資料夾複製到 `C:\TempleCloud`，並把 Node.js 22 以上的免安裝版放在 `C:\TempleCloud\node\`（`node.exe` 要在這個資料夾）。
6. 把 `temple-system` 資料夾裡的 `index.html`、`app.js`、`charter.js`、`poster.js`、`manifest.webmanifest` 放在 `C:\TempleCloud` 的上一層，也就是 `server.js` 的上一層資料夾（伺服器從那裡讀畫面檔）。
7. 資料放在 `D:\TempleData`（沒有 D 槽就用預設的 `local-server\data`）。
8. 工作排程器 → 建立工作：觸發「櫃台登入時」，動作執行 `C:\TempleCloud\start.bat`。
9. `櫃台` 帳號設定「指派存取」或只保留 Edge 捷徑，讓畫面開機就是本系統的全螢幕。
10. Windows Update 使用時間設為 7:00～22:00，只在半夜更新。
11. 連續開機 48 小時測試；**實際做一次備份，再到另一台主機還原**，確認成功才出貨。

## 到廟安裝

1. 接上 UPS（600～1000 VA），主機設定停電 5 分鐘後自動關機（系統關機前會自動備份）。
2. 開機後畫面出現「第一次啟用」：填宮廟名稱、管理員姓名與 PIN、**備份密碼**。
   - 備份密碼寫在兩張紙上，主委與總幹事各保管一張。忘了就無法還原，公司也打不開。
3. 「宮廟設定」新增人員：櫃台、會計、主委，各自設定 PIN。
4. 「備份・還原」→ 設定兩支備份隨身碟（貼上「備份 A」「備份 B」標籤）。A 常插，B 每週和 A 交換帶回家。
5. 準備一本預先編號的手寫收據（H0001 起），放在櫃台抽屜。

## 每日與每週

| 時間 | 誰 | 做什麼 |
| --- | --- | --- |
| 每天收班 | 會計或主委 | 「備份・還原」→「今日關帳」，把關帳結果和核對碼抄在日報上 |
| 每週 | 總幹事 | 交換備份隨身碟 A／B，帶一支離開廟 |
| 隨時 | 所有人 | 看右上角燈號：綠＝正常；黃＝沒插備份碟；紅＝超過 24 小時沒備份，請打電話 |

## 主機故障時（約 30 分鐘恢復）

1. 櫃台先改開**手寫收據**（H 開頭），照常收錢。
2. 打電話給公司，帶備用主機過去（或開啟廟裡的第二台）。
3. 備用主機開機 →「從備份還原」→ 選隨身碟 `TempleBackup` 資料夾裡日期最新的 `.tbak` → 輸入備份密碼。
4. 用原本的名字和 PIN 登入，所有收據、人員、設定都在。
5. 到「油香登記」→「補登手寫收據」，把故障期間的 H 單逐張補登（同一張不能補兩次）。

也可以用指令還原：`node\node.exe server.js restore E:\TempleBackup\backup_xxxx.tbak --data D:\TempleData`

## 安全設計摘要

- 伺服器只接受本機連線（127.0.0.1），同一個網路的其他電腦連不進來。
- 人員 PIN 用 scrypt 雜湊保存；連錯 5 次鎖 5 分鐘；閒置 15 分鐘自動鎖定。
- 作廢收據要會計、主委或管理員的 PIN 核准；櫃台不能關帳、不能看操作紀錄。
- 每個動作寫進操作紀錄並串成雜湊鏈，「操作紀錄」→「檢查紀錄有沒有被竄改」可以驗證；關帳核對碼抄在紙本日報上，日後可以比對。
- 備份檔用 AES-256-GCM 加密，金鑰由備份密碼經 scrypt 衍生。
- 主機上的 `config.json` 存有備份金鑰，所以主機本身一定要開 BitLocker。
